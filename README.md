# 🪨 Stupid Inventions

We create things nobody asked for.

Welcome to Stupid Inventions, an independent organization dedicated to developing unnecessary, questionable and occasionally functional inventions.

Our mission is simple: take perfectly good time, resources and programming skills, and turn them into something absolutely pointless.

Because if it works, why should it be useful?
